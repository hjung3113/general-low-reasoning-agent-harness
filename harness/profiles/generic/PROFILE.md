# Generic Profile

This profile is active when the repository stack is unknown or not yet confirmed.

Rules:

- Do not mention, run, scaffold, or recommend stack-specific commands from inactive profiles.
- Use repository evidence before choosing a runtime, package manager, test framework, database, or deployment target.
- Keep `.planning/codebase/**` marked as unhydrated until facts are recorded with evidence paths.
- Ask the user only for product intent or constraints the repository cannot answer.

Skill packs:

- No stack-specific workflow skill is installed by this profile.
