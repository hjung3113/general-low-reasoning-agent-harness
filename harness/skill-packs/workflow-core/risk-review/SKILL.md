# Risk Review

Use this skill before important commitments.

## Review Lenses

Pick lenses that match the task:

- low-reasoning clarity
- phase-gate safety
- data or state integrity
- user-facing behavior
- adapter compatibility
- portability
- verification coverage
- rollback and upgrade safety

## Output

Return findings by severity:

- issue
- evidence
- failure mode
- concrete reinforcement

Do not approve execute until P0/P1 findings are resolved or explicitly accepted.
