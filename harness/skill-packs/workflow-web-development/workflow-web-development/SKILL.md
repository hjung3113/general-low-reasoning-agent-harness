# Workflow Web Development

## Workflow

1. Identify user workflow, route or screen, data dependencies, and target devices.
2. Match existing component, styling, routing, and state conventions.
3. Define loading, empty, error, permission, and success states.
4. Pair with tech packs such as `tech-react`, `tech-typescript`, and `tech-tailwind` only when confirmed.
5. Verify with existing tests, build, and browser smoke checks.

## Stop Conditions

- design intent is unclear
- API contract is unknown
- responsive layout cannot be checked
- accessibility requirements are ambiguous
