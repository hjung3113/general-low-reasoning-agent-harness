# Workflow Data Analysis

## Workflow

1. State the analysis question and decision the output supports.
2. Identify input data, ownership, freshness, and privacy constraints.
3. Separate exploratory work from reproducible outputs.
4. Define expected tables, charts, reports, or metrics.
5. Verify against a deterministic sample or documented source.

## Stop Conditions

- data meaning is unclear
- sensitive data handling is undefined
- output decision is unknown
- verification requires unavailable production data
