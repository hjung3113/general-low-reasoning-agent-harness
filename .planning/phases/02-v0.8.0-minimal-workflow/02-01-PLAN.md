## Scope

Ship v0.8.0 with:

1. high-level machine JSON goldens for `HARNESS_MACHINE=1 harness next/run/check`;
2. high-level `harness`, `harness next`, `harness run`, and `harness check` behavior;
3. TTY-only human approval challenge and non-TTY approval refusal;
4. error scrub tests for normal command output, docs, and adapter prompts;
5. README and manual simplified workflow-first updates;
6. internal architecture UML and installed-user workflow UML under `docs/`;
7. Roo/OpenCode adapter prompt rewrite to the high-level machine flow;
8. compatibility, release, specialist, and Claude review gates;
9. v0.8.0 release metadata, tag, and push through the repo release process.

## Acceptance Criteria

- User-facing CLI count is four or fewer.
- Normal path works without flags and fits on one screen.
- Adapter flows do not require low-level phase knowledge.
- Hard boundaries and JSON/machine contracts remain tested.
- README, manual, and UML docs are updated.
- Tests and release checks pass.
- Final specialist and Claude reviews have no unresolved ship blockers.
- v0.8.0 is shipped via the repo release process.
