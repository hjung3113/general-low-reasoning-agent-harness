## Conventions

- **Backup path (exact):** `<root>/.harness/backups/<basename>.pre-repair.<ISO-8601-nanos>.<pid>.bak`
  - `<basename>` is `original.name` (e.g. `STATE.md`, `ROADMAP.md`), NOT a path. Two originals named the same in different dirs would collide on basename — out-of-scope (skeleton has one of each). Documented as a known limitation.
  - `<ISO-8601-nanos>` = `datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%S")` + `f"{time.time_ns() % 1_000_000_000:09d}"` separated by `_` → `20260516T143012_123456789`. Nanos resolution is required by the collision test (100 invocations in a tight loop on darwin can land in the same wall-clock second).
  - `<pid>` = `os.getpid()`.
- **Retention:** after a successful new `.bak` write, list `<root>/.harness/backups/<basename>.pre-repair.*.bak`, sort by mtime ascending, delete all but the 10 most recent. Pruning is best-effort: an unlink failure logs a warning but does NOT fail the repair.
- **`O_EXCL`:** `os.open(path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o644)`. If `FileExistsError` raises, repair aborts BEFORE touching the original (so the original is never lost). Surface as `BackupCollisionError` → exit 1 (operational error, distinct from exit 2 which is "refuse to act on malformed input").
- **Refusal exit code:** 2 for `RepairRefusedError` (malformed `phase-state.json`). 1 for operational failures (collision, atomic-write failure). 0 for success. Aligns with T0-3 CLI contract: `0=ok, 1=op-err, 2=input-err`.
- **Paused-phase line format (exact):** `- <phase-slug> (paused since YYYY-MM-DD)` rendered under a `### Paused Phases` H3 inside the `managed:state-current` payload, AFTER `## Active Checkpoint` and BEFORE any trailing newline. Emitted only when `phase_state.get("paused_phases")` is non-empty. Round-trip is via reading the same key back from the rewritten block payload (parser added in same slice).
- **Diagnostic format:** when `phase-state.json` is unparseable, stderr line: `state repair: refusing to rewrite — phase-state.json invalid at line N col M: <reason>. Fix the JSON or restore from .harness/backups/.` Exit 2. The string `"fix the JSON or restore from .harness/backups/"` is asserted verbatim by a test.
- **Duplicate slug:** if `parse_blocks(text)` yields two regions for the same slug (today this raises in `managed_block.parse_blocks`), catch and re-raise as `RepairRefusedError` with diagnostic `state repair: refusing to rewrite — duplicate managed block 'state-current' at line N and line M. Remove one block manually.` Exit 2.
- All file rewrites (ROADMAP, STATE, `.bak`) go through T0-A `atomic_write` (rename-into-place). `.bak` writes layer `O_EXCL` on top of that primitive (or use a direct `os.open` + `os.write` + `os.fsync` if T0-A's primitive does not expose `O_EXCL`; decision deferred to T0-A integration step).
- Imports stay stdlib-only.

  7. Return target path.

## Risk Log

- **R1 — `_wrap_section_in_block` end-marker heuristic** loses content if a user names a section starting with `## ` after `## Phases` but inside a fenced code block. Out-of-scope for T0-5 (pre-existing); document in plan but do not fix.
- **R2 — Basename-only `.bak` namespacing** collides if two originals share `name` (e.g. nested `STATE.md`). Skeleton has one; live repos have one. Documented limitation. Mitigation deferred.
- **R3 — `time.time_ns()` resolution on macOS** is 1µs on darwin, not true ns. Test uses 100 iterations which empirically never collide at µs resolution, but if CI tightens this becomes flaky. Mitigation: monkeypatch `time.time_ns` in the test to enumerate values explicitly. Already planned.
- **R4 — T0-A atomic primitive name** is not finalized at plan time. Integration step in Task 4 must be updated once T0-A lands. Plan does not block on T0-A code, only on the public symbol.
