# STACK - Harness Source

## Runtime

- Python standard library for installer, checker, doctor, and tests.
- Markdown for protocol, planning, adapter, profile, and skill-pack docs.
- JSON for manifest and phase gate state.

## Adapters

- Roo adapter files under `.roo/**`.
- OpenCode adapter files under `.opencode/**`.

## Profiles And Packs

- Generic profile under `harness/profiles/generic/`.
- Generic workflow skill pack under `harness/skill-packs/workflow-core/`.

No programming language, database, test framework, or deployment target is assumed for target projects.
