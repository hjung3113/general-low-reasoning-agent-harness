# TTY approval is the human checkpoint

`harness phase approve` is a TTY-only human checkpoint. No `--yes`, `--non-interactive`, or `--force-approve` flag exists, and none will be added. When the command detects a non-TTY environment — a pipe, a CI runner, a sub-agent invoking it programmatically — it exits with code 17 and refuses to advance the phase. This is not a missing feature; it is the contract.

The reasoning follows directly from ADR-0002 and the G6 grill session (2026-05-23). ADR-0002 established that the harness has no external attacker, so approval isn't authorization in the security sense. What approval *is* is a workflow checkpoint whose entire value is the human pause between phases. If the same agent that prepared the work can also approve the transition, the pause evaporates and the harness degrades to unreviewed automation — the exact failure mode the checkpoint exists to prevent. ADR-0001 makes the same point from the execution side: the harness is built around low-reasoning agents that pause at gates, not agents that run long autonomous chains. The TTY requirement is the gate made concrete.

The intended pattern for agent-driven workflows is: the agent runs `discuss`, `plan`, and `execute` phases; a supervising human runs `phase approve` interactively from a real terminal. This is not a limitation imposed on agents — it is the design. Sub-agents or smoke tests that call `phase approve` non-interactively will receive exit 17; that is correct behavior, and tests should assert it rather than route around it.

No escape hatch will be added. Any `--yes` flag — however narrowly scoped — invites scripted use that bypasses the human entirely, collapsing the checkpoint back to unreviewed automation. The cost of holding this line is low: supervised workflows work as designed. The cost of an escape hatch is the human-checkpoint contract itself. Reversing this decision would require documenting a new contract for what approval means when no human is present, which is a non-trivial undertaking; the standing rule keeps the boundary clear.
