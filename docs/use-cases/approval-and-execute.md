# 계획 승인 후 구현하기

## 언제 쓰나

계획 문서, 허용 경로, 검증 명령이 준비되었고 사용자가 구현을 승인하려는 시점에 사용합니다.

## 승인 전 확인

```bash
harness check
harness next
```

확인할 것:

- 계획이 현재 요청과 맞는가
- `allowed_paths`가 충분하지만 과도하지 않은가
- 검증 명령이 실제로 실행 가능한가
- 어댑터가 스스로 승인하지 않는가

## 승인 동작

```bash
harness run
```

`harness run`이 승인 안내를 출력하면 그 문구를 읽고 사람이 명시적으로 승인합니다. 에이전트나 어댑터는 사용자를 대신해 승인하지 않습니다.

## 승인 후 구현 조건

구현은 다음 조건이 모두 맞을 때만 시작합니다.

- live state가 execute 단계임
- 승인 출처 기록이 남아 있음
- `allowed_paths`가 비어 있지 않음
- `verification`이 비어 있지 않음
- `harness check`가 통과함

## 구현 중 범위 변경

요청이 계획 밖으로 커지면 구현을 멈춥니다. 새 파일이나 새 책임을 억지로 끼워 넣지 말고 계획을 갱신한 뒤 다시 승인받습니다.
