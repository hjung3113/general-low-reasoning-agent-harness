# 유즈케이스별 사용 안내

v0.9.6의 기본 원칙은 간단합니다. 보통 사용자는 네 명령만 기억합니다.

```bash
harness
harness next
harness run
harness check
```

케이스별 문서:

- [처음 설치하고 시작하기](first-install.md)
- [매일 쓰는 기본 작업 흐름](daily-workflow.md)
- [Roo/OpenCode 어댑터로 작업하기](adapter-agent-workflow.md)
- [계획 승인 후 구현하기](approval-and-execute.md)
- [문제가 생겼을 때 점검하기](troubleshooting.md)

저수준 `phase`, state repair, autopilot 명령은 고급/디버그/CI용입니다. 일반 사용 문서와 어댑터 문서는 이 명령들을 정상 경로로 요구하지 않습니다.
